# Contributing Guide

Thank you for contributing to Expense Tracker.

## How to Contribute

1. Fork the repository
2. Create a branch

git checkout -b feature-name

3. Make changes
4. Commit changes

git commit -m "your message"

5. Push branch
6. Open Pull Request


## Commit Style

feat:
New feature

fix:
Bug fix

docs:
Documentation


## Pull Requests

Please include:
- Description
- Screenshots
- Testing details
